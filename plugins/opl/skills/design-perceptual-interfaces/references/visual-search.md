# Visual hypotheses and extracted grammar

Use visual search when the design space is uncertain. Reuse the project's current
direction for a small edit. Load relevant previous episodes and actual references
before generating more candidates.

## Propose different representations

For substantial direction work, start with a small set, usually three distinct
directions. Compare differences such as spatial field, instrument, continuous
canvas, or typographic hierarchy. Palette swaps are not independent directions.
Expand only when the first set leaves a decision unresolved.

Use available built-in image generation for visual proposals when it helps.
Follow its current skill and tool contract. Do not require an API key, paid API,
subscription, external design editor, or new service. If it is unavailable,
use supplied references or executable sketches and state that limitation.

Describe a functional interface with real information, hierarchy, layout, viewing
conditions, and actions. Give semantic invariants and room for visual invention.
For adjacent states, specify what must remain identical and what alone changes.
Do not pass a generic list of fashionable components as art direction.

## Inspect and extract

Read the actual image before coding from it. Record:

- Composition: dominant structure, relative area, anchors, grouping, empty space.
- Type and contrast: scale relationships, reading order, quiet and urgent states.
- Materials and motifs: how identity, evidence, action, and containment differ.
- Geometry: coordinate frame, reference values, and what can be inferred from shape.
- State continuity: persistent objects, changed emphasis, and implied motion.
- Deviations: attractive features that misrepresent data, cannot survive resizing,
  omit a state, or depend on illegible text.

Extract rules that generalize to neighboring states. Rebuild text, controls,
layout, and semantics as real UI. Do not place a screenshot over missing controls.
Measure existing tokens and computed styles when adapting an existing product;
preserve discrepancies between the theme and values actually rendered.

## Select, implement, and compare

State which decisions were selected, rejected, and why. Use the user's choices
when available. Within authorized autonomous work, choose a provisional direction
and record the judgment as the model's. Do not fabricate human preference.

Implement a connected interaction, capture it at relevant sizes and states, and
compare with the grammar. Name concrete deviations instead of a quality score.
Change the source and rerender the affected views. Verify real behavior separately
from visual fidelity. Retain important corrections with their original problem
and limits; do not turn an instrument motif into a universal product style.
