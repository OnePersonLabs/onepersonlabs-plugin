ownership. Do not import the donor's general process supervisor, host converters,
scheduler, parallel lesson corpus, automatic confidence voting, or prescribed
branch/approval choreography. Preserve useful judgment and code independently of
those package boundaries. No model evaluations or new permanent invocation tests.

## Integrated mechanisms

The new implicit skills are `pov`, `develop-alternatives`, and `optimize`.
Instruction revision 61 routes consequential choices and measured improvement to
these owners. Research and feasibility callers reuse their evidence instead of
starting another survey. Project knowledge is selected by situation from declared
sources, including accepted Conceptor meaning, and cited where it changes the
brief, design, or finding. Handoff and authoring consumers use document evidence
checks; GitHub review repair uses immutable prepared receipts and fresh remote
publication checks. These are agent-selected branches, not developer opt-in flags.

Human collaboration is implicitly discoverable when the user requests substantive
participation. Hook recovery alone still cannot enroll a root or start a service.
The page adapter uses a child window opened by the inbox and sends only a draft
proposal. The authenticated inbox retains submission authority. Both origin and
source-window checks follow the browser's [postMessage contract](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage).
Page scripts receive no inbox bearer. Exact source state and element context stay
with each note; the normal claim/outcome protocol owns application and recovery.
Voice capture and paid transcription remain deferred: this unit preserves the
selected element-context feedback mechanism through text without another service.
Opener-isolated pages and tools without child-window injection use the existing
screenshot-and-inbox route; browser policies are not weakened.
